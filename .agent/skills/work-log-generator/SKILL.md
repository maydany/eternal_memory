# Work Log Generator Skill

이 스킬은 최근 대화 세션들을 분석하여 날짜별 작업 로그를 생성합니다.

## 실행 조건

- 사용자가 작업 로그 생성을 요청할 때
- `/work-log` 또는 유사한 명령 사용 시

## 실행 단계

### 1. 대화 세션 수집

대화 요약(conversation summaries)에서 최근 세션 정보를 확인합니다:
- 대화 ID
- 제목 (타이틀)
- 생성일 (Created)
- 마지막 수정일 (Last modified)

### 2. 날짜별 그룹화

세션들을 **Last modified** 날짜 기준으로 그룹화합니다:
```
2026-02-01: [세션1, 세션2, 세션3]
2026-01-31: [세션4, 세션5]
```

### 3. 기존 로그 확인 (중복 방지)

```bash
ls work_logs/
```

각 날짜에 대해:
1. `work_logs/YYYY-MM-DD_work_log.md` 파일 존재 여부 확인
2. 존재하면: 해당 파일의 "관련 대화 세션" 섹션에서 이미 포함된 세션 ID 추출
3. 새 세션만 추가 대상으로 필터링

### 4. 지식 베이스 및 대화 로그 조회

각 새 세션에 대해:
1. Knowledge Items(KI) 아티팩트에서 관련 정보 확인
2. 필요시 대화 로그 디렉토리 조회: `<appDataDir>/brain/<conversation-id>/.system_generated/logs/`
3. 핵심 작업 내용, 변경 파일, 기술적 결정사항 추출

### 5. 작업 로그 생성/업데이트

#### 새 파일 생성 (해당 날짜 로그가 없을 때)

`work_logs/YYYY-MM-DD_work_log.md` 파일 생성:

```markdown
# 작업 로그 - YYYY년 M월 D일

## 📋 작업 개요

**날짜**: YYYY-MM-DD  
**프로젝트**: [프로젝트명]  
**주요 작업**: [한 줄 요약]

---

## 🔧 1. [작업 제목]

### 작업 내용
- 상세 설명

### 변경 파일
- `path/to/file.py`

---

## ✅ 작업 완료 체크리스트

- [x] 완료된 항목
- [ ] 미완료 항목

---

## 🔗 관련 대화 세션

| 대화 ID | 주제 |
|---------|------|
| abc123... | 세션 제목 |
```

#### 기존 파일 업데이트 (새 세션 추가)

1. 기존 파일 내용 읽기
2. "작업 완료 체크리스트" 섹션 앞에 새 작업 내용 삽입
3. "관련 대화 세션" 테이블에 새 세션 추가
4. 체크리스트 항목 업데이트

### 6. README 업데이트

`work_logs/README.md` 파일 업데이트:
- 파일 구조 섹션에 새 로그 파일 추가
- 작업 로그 요약 섹션에 새 날짜의 요약 추가

```markdown
### YYYY-MM-DD
- **[작업1]**: 간략 설명
- **[작업2]**: 간략 설명
```

## 보안 규칙

**반드시 제외해야 할 내용:**
- API 키 및 시크릿
- 환경 변수 값 (변수명은 OK)
- 개인정보 (이메일, 전화번호 등)
- 데이터베이스 연결 문자열
- 인증 토큰

**포함해도 되는 내용:**
- 파일 경로 및 구조
- 기술적 설계 결정
- 코드 스니펫 (민감정보 제외)
- SQL 스키마 (샘플 데이터 제외)
- API 엔드포인트 경로

## 예시: 중복 실행 처리

**첫 번째 실행 (2026-02-02):**
```
입력: 세션 A, B, C (모두 2026-02-01)
결과: work_logs/2026-02-01_work_log.md 생성 (A, B, C 포함)
```

**두 번째 실행 (같은 날):**
```
입력: 세션 A, B, C, D (D는 새로 추가됨)
처리: 
  1. 기존 로그에서 A, B, C 이미 포함됨 확인
  2. D만 새 작업으로 추가
결과: work_logs/2026-02-01_work_log.md 업데이트 (D 추가)
```

## 출력 확인

작업 완료 후:
```bash
ls -la work_logs/
```

사용자에게 생성/업데이트된 파일 목록과 간략한 요약 제공.
