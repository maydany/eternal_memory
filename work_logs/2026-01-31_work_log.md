## 🔧 2. Semantic Triple 시스템 구현

### 2.1 Triple 기반 시맨틱 메모리 도입

#### 배경
기존 MemGPT 스타일의 바이너리 메모리 대체(Supersede) 방식은 복합 메모리에서 문제 발생:
- "나는 사과와 바나나를 좋아해" → "바나나는 이제 싫어"
- 기존 방식: 전체 메모리 비활성화 → 사과에 대한 정보도 손실

#### 해결책: Subject-Predicate-Object (SPO) 트리플
- 복합 문장을 원자적 단위로 분해
- `(User, likes, apples)` + `(User, likes, bananas)`
- 바나나 정보만 선택적으로 비활성화 가능

### 2.2 데이터베이스 스키마 확장

```sql
CREATE TABLE semantic_triples (
    id UUID PRIMARY KEY,
    memory_item_id UUID REFERENCES memory_items(id),
    subject VARCHAR(255) NOT NULL,
    predicate VARCHAR(255) NOT NULL,
    object TEXT NOT NULL,
    embedding VECTOR(1536),
    importance_score FLOAT,
    is_active BOOLEAN DEFAULT true,
    superseded_by UUID,
    created_at TIMESTAMPTZ
);
```
